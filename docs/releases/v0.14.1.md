# Osinara v0.14.1

Внешние Telegram-группы теперь могут импортировать в изолированный group Workspace дополнительные
текстовые форматы разметки и конфигурации без ослабления существующей проверки содержимого.

## Расширенный импорт вложений

- Capability импорта принимает UTF-8 документы с расширениями TXT, MD, JSON, CSV, TSV, HTML, XML,
  YAML и YML.
- Расширения сопоставляются без учёта регистра, поэтому, например, `PAGE.HTML`, `feed.Xml` и
  `settings.YAML` проходят тот же контракт, что и имена в нижнем регистре.
- Имя и metadata Telegram остаются только предварительным кандидатом. После скачивания backend
  повторно отклоняет определяемый binary type, некорректный UTF-8 и содержимое с NUL-байтами.
- PDF, DOCX, XLSX, архивы и произвольные бинарные файлы по-прежнему нельзя импортировать во внешний
  group Workspace.

## Проверка и deployment

- Regression-тесты покрывают metadata-классификацию, content validation и model-facing контракт для
  новых расширений и смешанного регистра.
- Production Compose graph, миграции и root-owned deployment controller не изменяются.
- Release публикуется только из canonical `main` через GitHub Actions с immutable GHCR digests,
  attestations и exact release assets. Установка требует отдельного owner approval в личном
  Telegram-чате.

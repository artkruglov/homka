# Osinara v0.14.3

Правило простой пунктуации внешних Telegram-групп теперь реализовано только через authored prompts,
без runtime-нормализации или post-processing ответа.

## Только prompting

- Удалён runtime normalizer, который заменял символы при сборке external mode block и grantable
  skill package.
- Permanent core, external mode fragments, model-facing descriptors и все файлы grantable `pohuy`
  skill очищены непосредственно в исходниках.
- Внешний prompt по-прежнему прямо запрещает длинное и короткое типографское тире, а также
  кавычки-ёлочки, и просит строить обычные разговорные фразы через простую пунктуацию.
- Пользовательские сообщения, история, память, файлы, tool data и итоговый ответ модели проходят без
  каких-либо замен.

## Проверка и deployment

- Unit tests только проверяют authored source и собранный external prompt во время разработки и CI;
  в production request path они не выполняются.
- Production Compose graph, миграции и root-owned deployment controller не изменяются.
- Release публикуется только из canonical `main` через GitHub Actions с immutable GHCR digests,
  attestations и exact release assets. Установка требует отдельного owner approval в личном
  Telegram-чате.

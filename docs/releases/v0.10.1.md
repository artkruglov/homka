# Osinara v0.10.1

Исправлен сетевой доступ встроенного T-Invest skill из trusted sandbox без ослабления TLS или обхода существующей egress policy.

## Причина

- Trusted sandbox подключён к internal Docker network и может выходить в интернет только через `sandbox-egress-proxy`.
- Встроенный Node.js `fetch` не использовал `HTTP_PROXY` и `HTTPS_PROXY` автоматически, поэтому T-Invest CLI завершался сетевой ошибкой до обращения к API.
- HTTPS endpoint T-Invest использует цепочку от Russian Trusted Root CA, которой нет в стандартном Mozilla CA bundle Node.js и Debian image.

## Исправление

- Для trusted sandbox включён штатный Node.js режим `NODE_USE_ENV_PROXY=1`.
- В sandbox runtime добавлен [официальный Russian Trusted Root CA Минцифры](https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt) со сроком действия до 2032 года.
- Сертификат передаётся Node через `NODE_EXTRA_CA_CERTS`; проверка TLS остаётся обязательной.
- Fingerprint сертификата `D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31` закреплён regression-тестом.
- Версия sandbox container policy увеличена, поэтому старые durable containers будут безопасно пересозданы с новой конфигурацией.
- Restricted external-group sandbox по-прежнему не получает сеть, proxy variables или дополнительный CA trust.

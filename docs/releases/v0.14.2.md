# Osinara v0.14.2

Ответы во внешних Telegram-группах получили более простой разговорный ритм без типографских тире и
кавычек-ёлочек, которые делали текст похожим на шаблонный ответ модели.

## Простая пунктуация внешнего режима

- External model policy теперь прямо запрещает длинное и короткое типографское тире, а также
  кавычки-ёлочки, и требует перестраивать фразу через точку, запятую или двоеточие.
- Общий permanent core больше сам не демонстрирует запрещённую типографику, поэтому внешний turn не
  получает противоречие между правилом и примерами.
- Полностью собранные authored external mode blocks и все файлы grantable group skill проходят
  отдельную нормализацию до передачи модели.
- Видимые Eve static skill descriptions и external tool descriptions следуют тому же контракту.
- Пользовательские сообщения, история группы, память, содержимое файлов и результаты внешних данных
  остаются byte-exact и не переписываются.

## Проверка и deployment

- Regression-тесты проверяют permanent core, полный external mode с каждой capability, external tool
  descriptions, static skill descriptors и все authored части grantable group skill.
- Production Compose graph, миграции и root-owned deployment controller не изменяются.
- Release публикуется только из canonical `main` через GitHub Actions с immutable GHCR digests,
  attestations и exact release assets. Установка требует отдельного owner approval в личном
  Telegram-чате.

# Osinara v0.15.5

Patch-релиз расширенного окна Telegram history поверх recovery-релиза `v0.15.4`.

## История разговоров

- Per-conversation retention увеличен с 1000 до 10 000 timeline messages.
- Максимум сообщений одного turn context увеличен с 50 до 100: до 99 предыдущих плюс текущее.
- Защитный предел `12 000` символов не изменён, поэтому длинные сообщения могут заполнить контекст
  раньше message limit.
- Оба лимита одинаково применяются к group journal и unified private/family conversation timeline.

## Memory Review Recovery

- Релиз включает не установленный ранее `v0.15.4`: audited bounded retry до Eve handoff, сохранение
  terminal source sets, безопасное восстановление заблокированной production lane и private owner
  alerts без неоднозначных повторов.

## Проверка

- Unit tests фиксируют exact лимиты `10 000` и `100`, а turn-context tests проверяют запрос 99
  предыдущих сообщений.
- Production-equivalent Docker Compose gate выполняется перед публикацией immutable release.

# Имя агента и обращения в Telegram

Имя задаётся установкой, а не сообщением пользователя. Один источник
`agent/lib/telegram-agent-identity.ts` используется в маршрутизации входящих сообщений,
блоке режима модели, подписи ответов в таймлайне и предупреждениях владельцу. В промптах,
описаниях инструментов и текстах подтверждений другого зашитого имени нет: там стоят
нейтральные формулировки («твой ответ», «собственный навык»), поэтому системный префикс
одинаков для любых имён.

По умолчанию имя — Хомка (14 сентября 2026). Обращения: Хомка, Хомки, Хомке, Хомку, Хомкой,
Хомкою, Homka, Khomka. Регистр не важен. Совпадение внутри слова, например «Хомкам», и
просто «хомяк» ответ не запускают.

Установка, которая по-прежнему называет себя Осинарой, задаёт `TELEGRAM_AGENT_NAME=Осинара`
и получает прежний набор обращений (Осинара, Осинары, Осинаре, Асинара, Сена, Osinara…).
Для другого имени или более узкого набора в `.env`:

```dotenv
TELEGRAM_AGENT_NAME=Хомка
TELEGRAM_AGENT_ALIASES='["Хомке","Хомку","Homka"]'
```

Пустое значение выбирает стандартный набор для известных имён (Хомка, Осинара); для другого
имени без заданных aliases действует только само имя. JSON `[]` явно выключает
дополнительные обращения. Можно задать до 32 вариантов длиной до 40 символов; это буквальные
имена, не регулярные выражения и не инструкции. Некорректная конфигурация останавливает запуск
с `AGENT_TELEGRAM_IDENTITY_INVALID`, не печатая её содержимое. Грамматика промптов женского рода
(«поняла»), поэтому имя тоже лучше выбирать с таким родом.

Слот памяти о стиле общения называется «общение с ассистентом» и от имени не зависит:
миграция 140 перенесла в него прежние записи «общение с Мией».

Оба Compose-файла передают настройки агенту. После изменения `.env` требуется штатно
пересоздать сервис агента. @username и reply по-прежнему проверяются по точной
Telegram-identity; имя не заменяет проверку членства, прав группы или получателя.
Неподдержанные slash-команды не становятся обращением только потому, что содержат имя.
Нормализация Unicode применяется только к копии для сравнения; сообщения, история, память и
файлы не переписываются.

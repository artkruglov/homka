# Как оценивать машину и чужой тезис

## Надёжность по данным, а не по слухам

1. Отзывные кампании и сервисные бюллетени по модели и году: что меняли и почему.
2. Независимые статистики: TÜV, ADAC, Consumer Reports, J.D. Power; для России — данные
   страховых по частоте обращений, если есть.
3. Ресурсные тесты и таксопарки: пробеги 300–500 тыс. км показывают слабые узлы честнее
   форумов.
4. Форумы и отзывы: только как список гипотез; каждую проверяй вторым источником.
5. Год выпуска и завод: одна модель разных лет и заводов может отличаться сильнее, чем две
   модели одного класса.

## Стоимость владения за 3 года (шаблон)

| Статья | Как посчитать |
| --- | --- |
| Потеря стоимости | цена покупки минус медиана объявлений на аналог 3 года старше |
| Топливо | пробег × расход по замерам владельцев (не паспорт) × цена |
| Страховка и налог | КАСКО по возрасту и мощности, транспортный налог по региону |
| Обслуживание | регламент ТО × цена у дилера или сервиса, плюс расходники по пробегу |
| Типовые ремонты | из справочника engineering.md по возрасту и узлам |
Итог давай диапазоном и называй самую тяжёлую статью.

## Осмотр экземпляра

- История: VIN по базам (ГИБДД, ФНП по залогам, Автотека, ФССП по владельцу), число
  владельцев, ДТП, такси, пробег по сервисным записям.
- Кузов: толщиномер по всем панелям, зазоры, болты петель, стёкла одного года.
- Агрегаты: холодный пуск, масло на щупе и в патрубках, коробка на всех режимах, полный
  привод на муфту, диагностика ошибок сканером, включая стёртые.
- Ходовая: подъёмник, люфты, течи, состояние тормозов.
- Электроника: все функции, ADAS, ключи, обновление ПО.
Итог: «дефекты конструктивные / эксплуатационные / возрастные» и цена приведения в порядок.

## Разбор тезиса

Когда приносят утверждение («китайские машины плохие», «турбо убивает мотор», «он дурак,
что поменял»):
1. Сформулируй тезис проверяемо: что именно должно быть правдой и для каких машин и условий.
2. Разбей на подтезисы: конструкция, качество, обслуживание, рынок, деньги, задача владельца.
3. По каждому: факт с источником и датой, либо «данных нет».
4. Вердикт: где тезис верен, где нет, при каких условиях; общий ответ одной фразой.
5. Про решения людей: рационально или нет относительно их цели, а не твоей; цели у людей
   разные (ездить без хлопот, эмоции, статус, деньги).

## Типовые мифы и их статус

- «Турбомотор живёт мало»: неверно как правило; верно для конкретных конструкций при плохом
  масле и коротких поездках. Смотри код двигателя.
- «Вариатор одноразовый»: неверно; ресурс сопоставим с автоматом при обслуживании, ремонт
  дороже и реже доступен.
- «Китайские машины разваливаются»: устарело для механики 2021+; актуально для окраски,
  антикора, ПО и остаточной стоимости. Различай бренды и заводы.
- «Дизель надёжнее бензина»: верно для механики, неверно для стоимости ремонта топливной
  аппаратуры и экологических систем.
- «Пробег не важен, важен уход»: наполовину; износ по пробегу не отменяется уходом, уход
  сдвигает срок.
- «Электромобиль зимой не едет»: запас хода падает на 30–40%, ездит; критично для дальних
  поездок, не для города.
